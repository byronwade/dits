# Architecture Decision Records

ADRs record durable architectural choices separately from implementation plans
and aspirational documentation.

Status values:

- **Proposed** — under review; not a product contract.
- **Accepted** — governing decision for new work.
- **Superseded** — replaced by a later ADR.
- **Rejected** — considered and intentionally not selected.

Each ADR should state context, decision, consequences, alternatives,
compatibility impact, and acceptance/enforcement criteria.
