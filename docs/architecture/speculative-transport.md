# Speculative Transport

**Maturity:** Design

Speculative upload, predictive prefetch, background remote transfer, and zero-latency synchronization are not current Dits capabilities. Network repository transfer fails closed. Any transport experiment must preserve exact object integrity and cannot claim complete repository semantics.

See [`../STATUS.md`](../STATUS.md), the
[active architecture](active-architecture.md), and
[core concepts](../concepts.md). Detailed formats remain implementation contracts until
an accepted ADR and conformance corpus make them public.
