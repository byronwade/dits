# Hybrid Local Architecture

**Maturity:** Current

Dits routes supported text through an embedded Git engine and binary/media content through Dits manifests and exact content-addressed chunks. This does not guarantee a savings percentage for any file, universal file-type understanding, or safe remote collaboration.

See [`../STATUS.md`](../STATUS.md), the
[active architecture](active-architecture.md), and the
[performance evidence](../performance/benchmarks.md). A proposal becomes Current only
after implementation, representative tests, and status promotion.
