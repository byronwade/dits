# QUIC Chunk Transfer Protocol

**Maturity:** Design

An in-process QUIC delta-transfer demonstration exists, but Dits has no complete negotiated repository protocol, remote authentication, authorization, resumable object contract, or atomic ref transaction. Network repository commands fail closed.

See [`../STATUS.md`](../STATUS.md), the
[active architecture](active-architecture.md), and
[core concepts](../concepts.md). Detailed formats remain implementation contracts until
an accepted ADR and conformance corpus make them public.
