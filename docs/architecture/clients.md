# Multi-Platform Client Strategy

**Maturity:** Design

The current product is a Rust CLI plus documentation and a local web playground. Desktop, mobile, NLE-panel, browser-sync, and public SDK clients are not Current. The npm package is a launcher for the binary targets actually included in its artifact.

See [`../STATUS.md`](../STATUS.md), the
[active architecture](active-architecture.md), and
[core concepts](../concepts.md). Detailed formats remain implementation contracts until
an accepted ADR and conformance corpus make them public.
