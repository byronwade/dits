# Architecture Overview

**Maturity:** Current

The active product is a local-first Rust engine and CLI with a standalone WASM playground wrapper. The hosted backend, databases, queues, managed object storage, SDK fleet, and complete remote protocol shown in older diagrams are not part of the active workspace.

See [`../STATUS.md`](../STATUS.md), the
[active architecture](active-architecture.md), and
[core concepts](../concepts.md). Detailed formats remain implementation contracts until
an accepted ADR and conformance corpus make them public.
