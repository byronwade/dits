# Cache Architecture

**Maturity:** Experimental

Dits includes bounded local cache and inspection paths used by selected CLI and optional VFS workflows. Distributed caches, remote prefetch services, CDN integration, cache-coherence protocols, and published capacity guarantees are Design.

See [`../STATUS.md`](../STATUS.md), the
[active architecture](active-architecture.md), and
[core concepts](../concepts.md). Detailed formats remain implementation contracts until
an accepted ADR and conformance corpus make them public.
