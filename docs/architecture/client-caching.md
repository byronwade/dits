# Client-Side Caching Strategy

**Maturity:** Design

The former multi-device and remote-client cache system is not implemented. There is no hosted cache API, cross-device coherence protocol, offline sync engine, or supported SDK cache contract. Selected local caches are implementation details.

See [`../STATUS.md`](../STATUS.md), the
[active architecture](active-architecture.md), and
[core concepts](../concepts.md). Detailed formats remain implementation contracts until
an accepted ADR and conformance corpus make them public.
