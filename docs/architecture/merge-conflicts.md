# Merge and Conflict Resolution

**Maturity:** Experimental

Local merge and related history commands are implemented, but binary and hybrid conflict handling is bounded and restore does not provide complete conflict resolution. Hosted review, semantic NLE merge, remote policy, and universal media conflict resolution remain Design.

See [`../STATUS.md`](../STATUS.md), the
[active architecture](active-architecture.md), and
[core concepts](../concepts.md). Detailed formats remain implementation contracts until
an accepted ADR and conformance corpus make them public.
