# Provenance Injection

**Maturity:** Design

Dits does not currently inject self-describing provenance into arbitrary media containers or guarantee that derivations can be reconstructed from embedded metadata. Current manifests and experimental FACR metadata are local repository records, not a universal provenance standard.

See [`../STATUS.md`](../STATUS.md), the
[active architecture](active-architecture.md), and
[core concepts](../concepts.md). Detailed formats remain implementation contracts until
an accepted ADR and conformance corpus make them public.
