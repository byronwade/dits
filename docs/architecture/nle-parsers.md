# NLE Project Parser Architecture

**Maturity:** Experimental

Selected EDL and OTIO demonstrations exist through experimental FACR commands. Universal Premiere, Resolve, Final Cut, Avid, After Effects, and binary project parsing is not Current, and semantic equivalence across NLE exports is not an exact content identity.

See [`../STATUS.md`](../STATUS.md), the
[active architecture](active-architecture.md), and
[core concepts](../concepts.md). Detailed formats remain implementation contracts until
an accepted ADR and conformance corpus make them public.
