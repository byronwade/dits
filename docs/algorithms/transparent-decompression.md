# Transparent Decompression

**Maturity:** Experimental

Selected structure-aware parsing and normalization experiments exist, but Dits does not transparently decompress arbitrary project formats or guarantee semantic deduplication. The former percentage savings, upload times, format matrix, and configuration block were modeled examples without retained benchmark evidence.

See [`../STATUS.md`](../STATUS.md), the
[active architecture](../architecture/active-architecture.md), and the
[performance evidence](../performance/benchmarks.md). A proposal becomes Current only
after implementation, representative tests, and status promotion.
