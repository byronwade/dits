# Workflow: Team Collaboration

**Maturity:** Design

Dits does not yet provide a supported shared repository, network clone, remote
push/pull/fetch/sync, account authorization, remote locks, hosted review, or conflict
coordination. Local branches and advisory locks are not a multi-user collaboration
service. Use local filesystem clone only for controlled copies and retain an external
source of truth for team work.

See [`../STATUS.md`](../STATUS.md), the
[current CLI reference](../user-guide/cli-reference.md), and
[Getting Started](../user-guide/getting-started.md).
