# P2P Sharing Guide

**Maturity:** Design

Dits does not currently provide peer discovery, rendezvous, NAT traversal, encrypted
peer sessions, invitations, or peer-to-peer repository transfer. Command scaffolding,
crypto helpers, and an in-process transport demonstration do not form a supported
sharing product or safe remote ref protocol.

Use local filesystem clone for current repository copying as documented in
[Getting Started](getting-started.md). See [implementation status](../STATUS.md) for the authoritative
boundary.
