# Rust SDK Guide

**Maturity:** Design

Dits does not publish the official language SDK or operate the hosted API assumed by
the former examples on this page. Tokens, organization endpoints, remote
clients, and webhook helpers are not current product behavior.

Use the local CLI documented in
[`../user-guide/cli-reference.md`](../user-guide/cli-reference.md) and consult
[`../STATUS.md`](../STATUS.md). Internal Rust crates and serialized types remain
pre-1.0 implementation details.

A public SDK requires a versioned protocol, conformance fixtures, release automation,
a support policy, and an independently published package.
