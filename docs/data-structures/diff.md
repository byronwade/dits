# Diff Data Structure

**Maturity:** Experimental

Local diff commands are implemented, including hybrid text/binary behavior, but Dits does not publish the hosted diff API, review model, media comparison schema, or stable machine-readable diff format formerly described here.

See [current CLI reference](../user-guide/cli-reference.md) and [`../STATUS.md`](../STATUS.md). Any serialized form not
explicitly governed by an accepted ADR and conformance corpus remains an implementation
detail.
