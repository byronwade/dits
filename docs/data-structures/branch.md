# Branch (The Pointer)

**Maturity:** Current

A local branch is a validated name whose ref file contains a commit hash. HEAD contains either a branch reference or a detached commit hash. Organizations, approvals, branch protection, remote tracking policy, and server-side authorization do not exist in the current product.

See [core concepts](../concepts.md) and [`../STATUS.md`](../STATUS.md). Any serialized form not
explicitly governed by an accepted ADR and conformance corpus remains an implementation
detail.
