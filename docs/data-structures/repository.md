# Repository (The Container)

**Maturity:** Current

A repository is a working tree plus .dits metadata, local refs, an index, Dits objects, and an embedded Git object database for routed text content. Local filesystem clone works. Hosted ownership, quotas, server IDs, and public repository formats are not Current.

See [active architecture](../architecture/active-architecture.md) and [`../STATUS.md`](../STATUS.md). Any serialized form not
explicitly governed by an accepted ADR and conformance corpus remains an implementation
detail.
