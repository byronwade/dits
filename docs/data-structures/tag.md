# Tag (The Milestone)

**Maturity:** Current

Current tags are validated local refs that point to commit hashes and can be listed, created, sorted, and deleted through the CLI. Hosted releases, protected tags, server signatures, and a public annotated-tag object format are not implemented.

See [current CLI reference](../user-guide/cli-reference.md) and [`../STATUS.md`](../STATUS.md). Any serialized form not
explicitly governed by an accepted ADR and conformance corpus remains an implementation
detail.
