# Dits support

Dits is alpha software maintained in public on a best-effort basis. There is no
paid support channel, guaranteed response time, or service-level commitment.

## Get help

- **Installation or usage question:** use the
  [question form](https://github.com/byronwade/dits/issues/new?template=question.yml).
- **Reproducible bug:** use the
  [bug report form](https://github.com/byronwade/dits/issues/new?template=bug-report.yml).
- **Focused product or design proposal:** use the
  [proposal form](https://github.com/byronwade/dits/issues/new?template=proposal.yml).
- **Real media fixture or workflow evidence:** use the
  [fixture form](https://github.com/byronwade/dits/issues/new?template=fixture.yml).
- **Current capability question:** check [`docs/STATUS.md`](docs/STATUS.md) and
  the [CLI reference](docs/user-guide/cli-reference.md) first.

Include the Dits version or commit, operating system, architecture, filesystem,
exact commands, smallest safe fixture, expected result, actual result, and hashes
when exact bytes matter.

## Protect sensitive information

GitHub issues are public. Never post secrets, private media, personal data,
proprietary project files, or unredacted paths and logs.

Report vulnerabilities through
the contact process in [`SECURITY.md`](SECURITY.md) before sharing technical
details. The initial contact request is public, so it must contain no sensitive
information.

## Alpha safety

Evaluate Dits only on disposable or independently backed-up data. Network
repository exchange, P2P, a hosted service, supported SDKs, and production
support are not shipped.
