# Contributors

Dits is currently led and maintained by [Byron Wade](https://github.com/byronwade),
who created the core architecture, Rust implementation, CLI, website, and
documentation.

GitHub's [contributors view](https://github.com/byronwade/dits/graphs/contributors)
is the authoritative record of merged code and documentation contributions.
Release notes will acknowledge contributors to each release.

## Add your contribution

Contributions are welcome across code, fixtures, testing, documentation,
performance reproduction, architecture review, and workflow research. Start
with [`CONTRIBUTING.md`](CONTRIBUTING.md) or the
[`good first issue`](https://github.com/byronwade/dits/labels/good%20first%20issue)
queue.

Acknowledgments are based on public, reviewable contributions. Dits does not
publish unnamed adopter, customer, or tester claims.
